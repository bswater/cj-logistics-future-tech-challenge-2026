# CJ대한통운 미래기술챌린지 2026

**참가 과제 2 · 랜덤 팔레타이징 알고리즘**

크기가 서로 다른 박스를 팔레트 위에 쌓는 순서와 배치를 결정하는 과제입니다. 팔레트 공간을 효율적으로 사용하면서, 쌓은 박스가 안정적으로 유지되도록 해야 합니다.

## 과제 조건

1. **박스 공급** — 크기가 다양한 박스가 순차적으로 공급됩니다.
2. **버퍼를 고려한 박스 선택** — 현재 버퍼 상태를 바탕으로 다음에 적재할 박스를 고르고, 적재 순서를 결정합니다.
3. **팔레트 배치** — 선택한 박스를 어디에 놓을지 정합니다. 같은 박스라도 놓는 위치에 따라 이후 박스에 남는 공간과 적재 안정성이 달라집니다.
4. **시뮬레이션 검증** — NVIDIA Isaac Sim에서 적재 결과를 검증합니다.

## NVIDIA Isaac Sim에서 적재 검증

팔레타이징 알고리즘은 버퍼에서 꺼낼 박스와 팔레트 위 배치 위치를 결정합니다. NVIDIA Isaac Sim의 물리 시뮬레이션에서는 이 배치를 재현하고, 중력과 박스 간 접촉이 작용한 뒤에도 적재 상태가 유지되는지 확인합니다.

- **공간 활용도** — 박스 배치가 팔레트의 적재 공간을 얼마나 효율적으로 사용하는지 평가합니다.
- **적재 안정성** — 박스가 밀리거나 넘어지면서 적재 상태가 무너지는지 확인합니다.
