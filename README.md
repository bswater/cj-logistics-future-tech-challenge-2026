# CJ대한통운 미래기술챌린지 2026

CJ대한통운이 주최한 물류기술 경진대회 참가 기록입니다. 대회는 실제 물류 현장의 문제를 바탕으로 참가자가 해결 방안을 설계하고 알고리즘을 개발하는 방식으로 진행됐습니다.

## 대회 과제

| 과제 | 목표 |
| --- | --- |
| 1. CCTV 영상 기반 화물 객체 분석 | 택배 상차 영상에서 레일 위 화물을 인식하고, 화물의 개수·유형·크기(가로·세로·깊이)를 추정하는 알고리즘을 개발합니다. |
| 2. 랜덤 팔레타이징 알고리즘 | 크기가 다양한 박스를 팔레트에 효율적으로 쌓도록 적재 순서를 최적화하고, 적재물이 안정적으로 유지되는지 검증하는 알고리즘을 개발합니다. |

참가팀은 한 과제를 선택하거나 두 과제를 모두 수행할 수 있었습니다.
